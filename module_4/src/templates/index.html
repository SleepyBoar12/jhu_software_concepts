Keep the analysis current

Pull Data checks for new data on the GradCafe website for fresh applications and adds the records to the PostgreSQL database.

It checks the five newest pages and avoids duplicate rows by using each application's unique GradCafe URL. The pull can take about a minute to finish. New rows are inserted immediately; LLM-based questions include them after the separate LLM enrichment step.

Update Analysis runs all analysis queries again using the latest committed PostgreSQL data. It is available after Pull Data finishes.
