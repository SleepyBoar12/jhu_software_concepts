To run the application, there are a number of ways you can do it:

(1) From "jhu_software_concepts/Module 1" folder, run the application "run.py"


(2) With the Terminal only, you can get to the correct folder, you can run the application by typing down "python run.py" and running it, like so:

$cd ".../jhu_software_concepts/module 1"
$source venv/bin/activate
$python3 run.py

As for me, I run the program through the terminal within VS Code.
I built the web application using MacBook (M1 series) with VS Code + Codex linked through GitHub
Intended for AWS website.

Finally, the application needs a Python virtual environment "venv" to which all of the dependencies are need to be installed. The libraries and dependencies in my virtual environment are:

- blinker 1.0.0
- click 8.5.0
- Flask 3.1.3
- itsdangerous 2.2.0
- Jinja2 3.1.6
- MarkupSafe 3.0.3
- Pip 25.2
